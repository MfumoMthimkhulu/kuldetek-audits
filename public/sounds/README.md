Place short notification audio files here named:

- notify.mp3
- notify.ogg

Recommended: a short (200-500ms) unobtrusive chime. You can create one with tools like Audacity or download a free chime. Keep file sizes small (<100KB).

If you prefer, use an existing sound file and name copies accordingly.

After adding the files, reload the app and test the chat. Some browsers require a user gesture (click) before audio playback is allowed; try clicking the page first if you don't hear sounds immediately.
